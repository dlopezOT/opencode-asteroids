# AGENTS.md

- This is a zero-dependency HTML5 canvas project.
- **Entrypoint:** `index.html` loads `game.js`.
- **Development:** Open `index.html` directly in a browser, or run `npx serve .` and visit `http://localhost:3000`.
- **Game Logic:** Entirely contained in `game.js`. No build step, bundler, or external dependencies required.
- **Controls:** Arrow keys for movement, Space to shoot.
